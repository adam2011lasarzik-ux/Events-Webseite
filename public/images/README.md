# Eigene Fotos einsetzen

Die Seite arbeitet zurzeit mit selbst gezeichneten Court-Grafiken und
markierten Fotoflächen. Sobald du eigene Bilder hast, ersetzt du die
Flächen damit.

## So gehst du vor

1. Lege deine Bilder in diesen Ordner (`public/images/`).
2. Benenne sie eindeutig, z. B. `court-falkensee.jpg`, `gruppe-2026.jpg`.
3. Sag Claude Code, welches Bild an welche Stelle soll — die Fotoflächen
   sind im Code als solche gekennzeichnet.

Empfohlene Größe: mindestens 1600 Pixel Breite, als `.jpg` oder `.webp`.
Größer als 2400 Pixel bringt nichts und macht die Seite nur langsam.

## Woher du kostenlose Fotos bekommst

Fremde Bilder einfach aus dem Netz zu kopieren, ist auf einer Seite, mit
der du Geld einnimmst, ein echtes Abmahnrisiko. Diese beiden Quellen
stellen Fotos bereit, die auch gewerblich genutzt werden dürfen:

- **Unsplash** — unsplash.com, Suchbegriff `padel`
- **Pexels** — pexels.com, Suchbegriff `padel`

Prüfe trotzdem immer die Lizenz des einzelnen Bildes, bevor du es
verwendest, und hebe dir auf, woher es stammt.

## Wichtig bei Fotos von Teilnehmern

Sind Personen erkennbar, brauchst du vor der Veröffentlichung ihre
Einwilligung. Bei Minderjährigen die der Erziehungsberechtigten.

Die Anmeldung wird später eine getrennte, freiwillige Foto-Einwilligung
abfragen. Veröffentliche nur Bilder von Personen, die zugestimmt haben.
